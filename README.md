# 🧮 Basic Calculator in C

A beginner-friendly **menu-driven calculator written in C** as part of my early programming practice during BCA.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Menu-driven interface
- Basic input validation
- Division-by-zero protection

## 🛠️ Technologies

- C
- GCC
- Standard C input/output

## 🎯 What I Practiced

This project helped me practice:

- Variables and data types
- Arithmetic operators
- Conditional logic and control flow
- User input and output
- Basic error handling
- Program structure

## ▶️ Run Locally

Compile with GCC:

```bash
gcc calculater.c -o calculater
./calculater
```

## 📌 Project Level

**Beginner / Fundamentals**

This is an early learning project. I’m using these fundamentals to build toward Python, DSA, data analysis and AI/ML.

## 💡 Example

```text
===== BASIC CALCULATOR =====
1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit
```

The program asks for two numbers after selecting an operation and prints the result.
